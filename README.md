# OmoiLog

演唱會無料交換與領取手帖。純前端、無執行期相依套件；資料與截圖透過 IndexedDB 儲存在使用者裝置，不會傳送到伺服器。

## 本機啟動

需要 Node.js 20 以上，執行 `npm run dev` 後開啟 http://localhost:5173 。不需要 npm install。請透過 HTTP 開啟，勿直接雙擊 HTML。

## 使用

建立演唱會場次後新增交換／領取紀錄，或在歡迎頁載入可刪除的示範資料。搜尋支援多個關鍵字交集、社群帳號、暱稱、hashtag、交換類型、物品、地點與備註，可搭配狀態、類型、標籤篩選。

CSV：在場次內選擇匯入，對應欄位，預覽並選擇略過／更新／另建重複資料。重複依帳號（無帳號時用暱稱）、平台及類型判斷；更新保留原截圖、狀態並合併備註。錯誤列提示列號且不匯入，請修正後再匯。時間建議 HH:mm，類型使用 app 提供的三個名稱。Google 表單附件不自動下載。

備份：側欄或手機上方的「備份」可匯出包含截圖的 JSON，還原會覆蓋所有資料。CSV 匯出只有文字；為降低試算表公式執行風險，部分以特殊字元開頭的欄位會加單引號。

PWA：首次連線載入後快取 app 檔案，可離線開啟。安裝選項由瀏覽器提供，iOS 可使用「加入主畫面」。資料依裝置、瀏覽器與網址分開，清除網站資料會刪除紀錄。請定期備份。圖示目前採 SVG，部分平台安裝圖示支援可能不同。

## 檢查

`npm test` 測試搜尋、CSV、重複辨識、備份驗證；`npm run check` 檢查 JavaScript 語法。尚需實機驗證行動版、IndexedDB 附件儲存與離線安裝流程。

## 圖片儲存與壓縮（新版）

第一次開啟新版會將舊版內嵌圖片轉為獨立的 IndexedDB Blob，紀錄只保存圖片識別碼。升級不會壓縮圖片；所有紀錄、圖片順序與狀態維持原樣。轉換與資料切換使用同一個交易，失敗時保留舊資料。若提示升級被阻擋，先關閉其他 OmoiLog 分頁再重新開啟。多分頁過期的文字資料不會覆蓋新資料。

新加入圖片預設「標準」（長邊 1,920 px、品質約 82%），也可選擇「文字清晰」（2,560 px／90%）或「保留原圖」。小圖不放大，壓縮結果較大則保留原圖，GIF 保留原檔。150～300 KB 是優化目標，並非每張圖片的大小保證。單張原圖上限為 20 MB。

圖片由「X 張圖片，點選展開」開啟左右滑動相簿，提供上一張／下一張與張數提示。只載入當前與相鄰圖片，收起或關閉視窗會釋放預覽資源。

既有圖片需至「備份 → 最佳化既有圖片」手動執行，先另存完整 JSON 並勾選確認，再選模式開始。可中途停止；只取代成功且較小的圖片，失敗保留原圖。使用相同模式處理過且已縮小的圖片不會再次重壓縮。備份匯入後壓縮模式紀錄不保留，可再次手動最佳化。

新版完整 JSON 仍包含所有圖片，可還原舊版 JSON；匯出時逐張讀取圖片並分段建立檔案。CSV 只有文字。圖片已從文字資料分離，請勿直接將內部資料庫內容當作完整備份。匯出完成後先確認檔案已保存。

備份視窗會顯示圖片大小及瀏覽器配額估算，並可要求持久儲存；是否允許由瀏覽器決定，不取代定期備份。`records_backup/` 與 `outputs/` 皆由 Git 忽略。

## 圖片功能驗證

網站仍不需要執行期套件；執行測試前先 `npm ci` 安裝開發套件，再執行：

```powershell
npm run check
npm test
npm run test:browser
```

瀏覽器測試使用獨立、無頭的 Edge／Chrome 設定檔，以 390×844 手機尺寸驗證。Windows 預設尋找已安裝的 Edge 或 Chrome；其他環境可設定 `OMOI_BROWSER` 為 Chromium 瀏覽器執行檔路徑。若 `records_backup/` 存在 JSON，測試只讀取副本並核對原檔 SHA-256，不寫回備份。測試輸出存於忽略的 `outputs/`。手機 Safari 的解碼、觸控與離線安裝仍應實機確認。
