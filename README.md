# omoi log

演唱會無料交換與領取手帖。純前端、無執行期相依套件；資料與截圖透過 IndexedDB 儲存在使用者裝置，不會傳送到伺服器。

## 本機啟動

需要 Node.js 20 以上，執行 `npm run dev` 後開啟 http://localhost:5173 。不需要 npm install。請透過 HTTP 開啟，勿直接雙擊 HTML。

## 使用

建立演唱會場次後新增交換／領取紀錄，或在歡迎頁載入可刪除的示範資料。搜尋支援多個關鍵字交集、社群帳號、暱稱、hashtag、交換類型、物品、地點與備註，可搭配狀態、類型、標籤篩選。

CSV：在場次內選擇匯入，對應欄位，預覽並選擇略過／更新／另建重複資料。重複依帳號（無帳號時用暱稱）、平台及類型判斷；更新保留原截圖、狀態並合併備註。錯誤列提示列號且不匯入，請修正後再匯。時間建議 HH:mm，類型使用 app 提供的三個名稱。Google 表單附件不自動下載。

備份：側欄或手機上方的「備份」可匯出包含截圖的 JSON，還原會覆蓋所有資料。CSV 匯出只有文字；為降低試算表公式執行風險，部分以特殊字元開頭的欄位會加單引號。

PWA：首次連線載入後快取 app 檔案，可離線開啟。安裝選項由瀏覽器提供，iOS 可使用「加入主畫面」。資料依裝置、瀏覽器與網址分開，清除網站資料會刪除紀錄。請定期備份。圖示目前採 SVG，部分平台安裝圖示支援可能不同。

## 檢查

`npm test` 測試搜尋、CSV、重複辨識、備份驗證；`npm run check` 檢查 JavaScript 語法。尚需實機驗證行動版、IndexedDB 附件儲存與離線安裝流程。
